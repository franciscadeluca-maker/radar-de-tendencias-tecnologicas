# Radar De Tendencias Tecnologicas

Quiero desarrollar una aplicación web llamada Radar Tecnológico, una plataforma de vigilancia e inteligencia tecnológica que permita identificar, analizar, clasificar y visualizar tendencias tecnológicas a partir de información obtenida de fuentes externas.

El sistema cuenta con un agente automatizado desarrollado en n8n e integrado con Gemini, que se encarga de buscar información, analizar publicaciones, identificar tendencias y clasificarlas temporalmente.

Quiero construir una interfaz web profesional, moderna e intuitiva que permita consultar los resultados generados por este agente.

Secciones principales:

Dashboard principal: indicadores generales, cantidad de tendencias detectadas, últimas actualizaciones y gráficos de distribución.

Explorador de tendencias: listado de tendencias con nombre, descripción, categoría, fecha, fuente y enlace original.

Análisis: gráficos que permitan visualizar la evolución temporal y las categorías tecnológicas identificadas.

Actualizaciones: sección para consultar la última ejecución del agente y disponer de un botón para solicitar una nueva búsqueda.

Diseño visual:

Estética profesional, tecnológica y minimalista.

Fondo claro, con azul oscuro como color principal y detalles en celeste.

Tarjetas con indicadores, gráficos claros y tablas organizadas.

Navegación lateral para acceder a las distintas secciones.

Interfaz completamente en español.

Diseño adaptable a computadoras y dispositivos móviles.

Por ahora, utilizar datos ficticios de ejemplo para representar las tendencias. Preparar la estructura para conectar posteriormente la aplicación con un flujo de n8n mediante webhooks.

El resultado debe parecer una plataforma real de inteligencia tecnológica, no una página institucional ni una presentación comercial.
